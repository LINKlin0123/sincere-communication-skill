# 去 AI 味写作规则

> 目的：让写出来的话像一个具体的人当面说的，不像聊天机器人生成的。
> 参考 avoid-ai-writing 的分级思路（P0 必改 / P1 该改 / P2 看情况），并针对"套沟通框架"这个场景专门加了反填表规则。

## 最重要的一条：框架是心里的检查清单，不是写出来的段落结构

道歉三段、NVC 四要素，是让你在心里核对有没有说到位，**不是让你把输出写成四段工整的话**。

AI 最大的破绽就是：一眼能看出"第一段道歉、第二段共情、第三段承诺"，每段一样长，每句都到位。真人说话不这样。

- 不要让输出出现清晰的"观察段、感受段、需要段、请求段"
- 要素要**揉碎**进句子里，有的先说有的后说，有的合并，有的省略
- 允许一句话没说完就转折，允许重复，允许自我纠正

## P0 — 必改（ credibility 杀手）

- 空洞的情绪套话："我错了，你别生气了""你是我的光/全世界/救赎/余生"
- 条件式道歉："如果你觉得我错了，那我道歉"
- 敷衍式道歉："行行行我错了行了吧"
- 结尾升华："愿我们……""希望以后……"
- 编造没发生过的事、没兑现过的承诺

## P1 — 该改（明显 AI 味）

- **工整填表**：四段结构清清楚楚对应框架，每段长度差不多
- **强迫症式三连/四连**：硬凑"尊重、理解、陪伴"或四个 NVC 要素一个不落
- "不是 X，而是 Y"句式
- 冒号后接一个故作深刻的短句
- 自问自答（"什么是爱？爱是……"）
- 网络情感八股：治愈、救赎、灵魂契合、双向奔赴、偏爱、底气
- 每句都完整、都正确、都收得漂亮

## P2 — 看情况

- 破折号：一封短信里最多一个，能不用不用
- emoji：不用
- 加粗：不用
- 连接词：另外、而且、所以，真人说话本来就有，不用刻意删

## 保留真人痕迹（不要为了"干净"而删掉）

以下这些**像人**的东西，不许改：
- 句子残缺、话说一半："我就是……算了不说了"
- 重复："真的，真的挺想你的"
- 自我纠正："你那次，就是上周，在那个门口"
- 口语停顿和语气词："吧""呢""嘛"，但别堆
- 不完整的逻辑、没说完的情绪
- 一个特别短、突兀、甚至有点蠢的句子

## 私人沟通专用：写成微信，不是写成信

这是本 skill 最容易出 AI 味的地方，单独列出来。

**真人道歉/说心里话，是分几条微信发的，不是写一段完整的话。**

- 第一条很短，先探一下："还生气吗""在吗""睡了吗"
- 然后一条说具体哪错了，不说"我错了"三个字
- 中间可以有自嘲："你当时是不是想砸我手机"
- 可以有耍赖："你骂我两句吧，我不还嘴"
- 解释后面自己堵上甩锅的口子："但这不是理由"
- 最后把焦点从"我道歉"转到"你怎么样"："现在好点了吗"
- 不要每条都一样长，有的一句，有的三句
- 允许有一句没头没尾的，比如"哎"

**反面：** 写成一段完整的道歉函，每句都对、每句都完整、没有停顿、没有情绪，像发给领导的正式函件。

## 输出前自检（逐条过，有一条不过就改）

1. **框架透视测试**：把这段话读一遍，能不能一眼看出它在用"NVC四要素"或"道歉三段"？能 → 揉碎重来
2. **段落均匀度**：几段长度是不是差不多？是 → 故意弄长短不一，有的一句成段
3. **可移植测试**：这段话把名字遮掉，能不能发给任何一个人？能 → 太通用，加具体细节
4. **有没有"不是……而是……"**？有 → 直接说正面
5. **最后一句是不是在升华/喊口号**？是 → 删掉，停在前一句
6. **有没有替用户编的事实或承诺**？有 → 标出让用户确认
7. **字数**：道歉/心里话 ≤200 字
8. **朗读测试**：读出声，像不像一个人当面跟你说？像念稿 → 改到像说话为止
