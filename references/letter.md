# 写信框架（情书 / 表白 / 纪念日 / 心里话）

## 核心判断
一封信打不打动人，不取决于文采，取决于**有没有只有你们俩才有的东西**。
通用情话（你是我的光、余生请多指教）可以发给任何人，所以不值钱。

## 写信前必须采集的素材
1. 关系阶段：刚追 / 在一起多久 / 异地 / 纪念日
2. 一件具体的事：某个场景里他做了什么（时间、地点、动作）
3. 一个小怪癖：他身上别人无所谓、你却记住的小动作
4. 这封信要干嘛：表白 / 日常想念 / 纪念日 / 让对方安心

第 2、3 项给不出来，先让用户去想，不要用空话填。

## 结构（不要求严格照此，但要素要在）
- 从一个具体画面切入，不要"亲爱的""见字如面"开头（除非用户要）
- 中间写你真实的感受和你注意到的细节
- 结尾停在一个具体的东西上，不升华

## 语气
- 用第二人称"你"
- 句子长短不一，允许短到三五个字
- 允许一点笨拙、一点说不出口，比漂亮话真实

## 禁忌
- "你是我的光/全世界/唯一/救赎"
- "余生请多指教""往后余生"
- 排比堆砌（"是你让我……是你让我……是你让我……"）
- 结尾"愿我们……""希望我们……"式升华
- 超过 200 字（越长越像抄的）
- emoji
